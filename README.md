# Hệ thống bán hàng và thanh toán quán cà phê

Giao diện demo quản lý quán **Gỗ Coffee**, xây dựng bằng ASP.NET Core Blazor Server và .NET 10.

## Chạy ứng dụng

Cài .NET 10 SDK, mở terminal tại thư mục gốc dự án và chạy:

```powershell
dotnet run --project CuaHangTienLoi.Web/CuaHangTienLoi.Web.csproj
```

Mở địa chỉ localhost được hiển thị trong terminal. Ở màn hình đăng nhập, tài khoản demo là `admin@moc.coffee`; mật khẩu có thể là bất kỳ giá trị nào.

## Chức năng demo

- Tổng quan doanh thu và đơn hàng.
- Bán hàng, giỏ hàng và thanh toán.
- Quản lý đơn hàng và trạng thái.
- Quản lý thực đơn và kho nguyên liệu.
- Báo cáo doanh thu.
- Quản lý nhân viên, vai trò và ca làm.

Dữ liệu nghiệp vụ hiện là dữ liệu mẫu trong bộ nhớ để trình diễn giao diện.
